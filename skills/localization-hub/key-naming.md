# Key Naming

- UI: `ui.nav.pricing`
- Route slug: `route.public.pricing`
- SEO: `seo.pricing.title`
- Static blocks: `static.home.hero.title`
- Mail: `mail.invitation.subject`
- Notifications: `notification.subscription.expiring`

Rules:

- use stable semantic names
- avoid page-text-as-key
- keep Turkish source text in `source_text`
- use `surface`/`domain` for classification, not key prefix alone
